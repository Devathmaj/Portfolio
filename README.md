# Devathmaj A Kaliyathan - Portfolio

Welcome to the source code of my personal portfolio website! This project serves as a showcase of my work in backend engineering, distributed systems, and observability, designed with a focus on smooth interactions, clean code, and a reliable user experience.

## 🎯 About Me
I am a CS undergraduate focused on backend reliability, observability, and distributed infrastructure. I design systems that measure themselves, scale cleanly, and ship with clear operational insight from day one.

**Core Focus Areas:** Observability / Reliability / Platform / Delivery

## ✨ Features
- **Custom Terminal Interface**: Try interacting with the built-in "Coastal Console" right on the homepage.
- **Smooth Page Transitions**: GSAP-powered animations for a seamless browsing experience.
- **Responsive Design**: Optimized layout across mobile and desktop.
- **Interactive Project Showcase**: View details about my production systems and architecture.
- **Modern Build System**: Built with Vite for rapid development and optimized production builds.

## 🚀 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Devathmaj/web-development-portfolio-main.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🌐 Deployment
This portfolio is configured to be deployed as a static site. You can easily deploy it using GitHub Pages via the included `.github/workflows/static.yml` action, or on platforms like Vercel, Netlify, or standard web servers by uploading the output of the `dist/` directory.
